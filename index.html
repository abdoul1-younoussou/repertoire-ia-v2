Le rapport est généré par GitHub Actions (exécution manuelle ou hebdomadaire). Le bouton ci-dessus recharge le dernier rapport publié ; il ne lance pas lui-même le vérificateur. Les réponses 401, 403 et 429 sont classées « non vérifiables » et ne sont pas assimilées à des liens morts. Aucun lien n'est modifié automatiquement.

Pour produire un nouveau rapport : GitHub → Actions → Vérification hebdomadaire des liens → Run workflow. Cette action nécessite que le projet soit dans un dépôt GitHub.
